# RTSS Lite — 빠른 물리치료 회기 기록

재활치료 명세체계(Rehabilitation Treatment Specification System, RTSS)의 핵심을 한 화면의 세 단계로 기록하는 교육·파일럿용 프로그램입니다.

기존 정밀 관리용 버전은 그대로 보존되어 있습니다.

- 기존 버전: `/Users/coding/Documents/RTSS/rtss-clinical-chart-mvp`
- Lite 버전: `/Users/coding/Documents/RTSS/rtss-clinical-chart-lite`

## 기록 흐름

1. 환자 생활목표: 비식별 사례 코드, 기록일, 환자가 실제 생활에서 하고 싶은 일
2. 오늘의 치료: 직접 치료표적 한 가지, 실제 치료방법, 작용기전 가설, 실제 제공량과 즉각 반응
3. 결과·다음 결정: 결과측정 상태, 안전 상태, 다음 회기의 유지·진행·조정·보류 결정

차트 문장을 복사하면 시간표시가 있는 최근 기록이 이 브라우저에 자동 보관됩니다. 목록에 없는 치료표적·치료방법·작용기전·평가도구를 직접 입력하면 `기관 검토 전 사용자 항목`으로 이 기기의 추천 목록에 추가됩니다.

임상영역을 선택하면 해당 영역의 직접 치료표적만 명시적인 선택 목록으로 표시됩니다. 치료표적 검색창에서는 한글·영문 명칭, 변화방향, 연결된 평가도구, ICF 코드와 표적 설명의 관련 키워드를 검색할 수 있습니다.

작용기전 71개와 결과측정 도구 39개도 별도 검색창과 선택 목록으로 제공합니다. 결과측정 상태나 치료표적을 바꿀 때 기존 값이 있으면 초기화 전에 확인하며, 안전 상태는 이상반응·치료 중단·치료 미실시를 구분합니다.

## 실행

```bash
npm ci
npm run dev -- --port 3001
```

브라우저에서 `http://127.0.0.1:3001`을 엽니다. 기존 버전을 3000번 포트에서 함께 열어 비교할 수 있습니다.


## 포함된 기준정보

RTSS 뇌졸중 물리치료 분류체계 DB v3.2(`../분류체계DB/RTSS_stroke_PT_db_v3.2.json`)를 사용합니다.

- 12개 임상영역
- 87개 직접 치료표적
- 123개 치료방법
- 71개 작용기전
- 110개 치료 구성 참고안(참고안 목록에 2026 AHA/ASA 지침 기준 권고 강도 판정 표시)
- 39개 평가도구와 문헌 기반 기준선 도움말

DB v3.2에서 평가도구 ID가 바뀌었습니다. 이전에 저장한 기록의 뇌졸중 영향 척도(O36)와 미국 국립보건원 뇌졸중 척도(O37)는 앱을 열 때 자동으로 O38·O39로 옮겨집니다. v3.2의 O36·O37은 원격·자기관리 프로그램 실천 기록과 목표 심박대 유지 시간·걸음 수입니다.

치료표적을 선택하면 연결된 핵심 치료방법·작용기전·용량 참고를 보여주지만 자동 처방은 하지 않습니다. 평가도구를 선택하면 점수 형식, 기록 조건, 좋아지는 방향과 문헌 링크를 접어서 확인할 수 있습니다.

## 안전 원칙

- 합성 또는 비식별 사례만 입력합니다. 실명, 등록번호, 연락처 등 식별정보를 입력하지 않습니다.
- 브라우저 내부 저장은 편의를 위한 임시 보관입니다. 기관 전자의무기록, 전자서명, 법정 의무기록, 보험 청구를 대체하지 않습니다.
- 문헌상 용량과 변화 참고값은 자동 판정·진단·처방이 아닙니다. 대상군, 회복시기, 검사절차가 근거 원문과 맞는지 치료사가 확인해야 합니다.
- 새로 입력한 사용자 항목은 표준항목이 아니며 기관 검토 전 상태로 표시됩니다.
- 같은 브라우저의 여러 탭에서 동시에 편집하지 않습니다. 다른 탭의 변경이 감지되면 최신 자료를 다시 열어야 합니다.
